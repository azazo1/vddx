# VDDX v0.1.0

Date: 2026-11-01

首个公开版本, 提供 macOS 15 上的虚拟屏创建与管理, 以及把虚拟屏画面镜像到普通窗口.

## Highlights

- 任意创建与销毁虚拟屏, 支持自定义分辨率, 刷新率与 HiDPI.
- 菜单栏常驻, 主窗口集中管理, 关闭窗口后继续运行.
- 镜像窗口可以看到虚拟屏的实时画面.

## Features

- 虚拟屏: 创建, 编辑与销毁任意数量的虚拟屏, 支持 640x480 到 7680x4320 的分辨率, 24 到 240 Hz 刷新率与 HiDPI.
- 持久化: 标记为"应用启动时自动重建"的虚拟屏会在下次启动时自动恢复.
- 菜单栏: 左键显示主窗口, 右键菜单提供新建虚拟屏, 镜像, 设置, 检查更新与退出.
- 镜像: 用 ScreenCaptureKit 捕获指定的虚拟屏, 在独立窗口中按原始比例显示, 支持窗口全屏.
- 系统设置: 主窗口可直接打开系统显示器设置; 设置页提供屏幕录制权限入口.
- 启动: 支持启动时隐藏主窗口并只驻留菜单栏, 隐藏主窗口时同时隐藏 Dock 图标.
- 日志与数据: 日志按天与文件大小轮转, 保存在 `~/Library/Logs/com.azazo1.vddx/`; 数据保存在 `~/Library/Application Support/com.azazo1.vddx/`.

## Upgrade Notes

1. 首次使用镜像功能时, 需要在 系统设置 > 隐私与安全性 > 屏幕与系统音频录制 中手动添加 VDDX 并勾选. macOS 15 起该权限不再自动弹窗, 授权后需要重新打开应用.
